# DroneHacks starter — no GPU queue required

Read onboard/README.md and AI_CONTEXT.md first. The native ROS/PX4
takeoff example is onboard/examples/takeoff_land.py. The Learn notebook
is under learn/; its GNSS lesson is a general reference, not indoor flight.
The cloud companion is x86 Jazzy/IsaacROS4; ARM JetPack/Humble differs.
This download executes nothing and contains no
credentials, team files, GPU image, course mesh or hidden flight code.

You can read/edit code offline. Flight needs ROS2 matching your target distro,
matching px4_msgs, an active uXRCE-DDS link and a healthy
PX4 estimate. An offline laptop is not a running simulator. On hardware,
calibrate the actual CameraInfo/TF, rates, IMU, firmware and flight gates
before flight. Your lab email code is not an SSH or sudo password.
